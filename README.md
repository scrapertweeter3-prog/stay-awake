# Stay Awake

A tiny app that keeps your computer from sleeping. One button, done.

Useful when a long build, a download, or a remote session is running and you
do not want the screen to go dark and the box to idle out.

## What it does
- Blocks the system idle timer while open
- Optional "fake activity" mode that jitters the cursor every 30s
- Menu-bar / tray icon, one-click to toggle

## Stack
Python + a lightweight GUI toolkit, packaged for Windows and macOS.
